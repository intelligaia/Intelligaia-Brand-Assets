# Case Study Graphics

One folder per project. Graphics only — no HTML, no PDF write-ups
(those live in `website/_documents/case-studies/`).

## Convention

```
case-studies/<project-slug>/
    hero.png                 the lead image
    01-<topic>.png           numbered in the order they appear on the page
    02-<topic>.png
```

`<project-slug>` is lowercase, hyphenated, and matches the case study's
URL slug on the site.
