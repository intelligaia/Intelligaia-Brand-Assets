Part 1 · The System

Construction process.

Every illustration in this library is built through the same 4-stage mechanism. Grid establishes structure, deconstruction lays the geometric primitives, outlining commits the silhouette, filling delivers the finished asset. Only the last stage ships — the others are process, not style.

01

Grid.

Every illustration starts on the 50×50 dot-pixel grid. Establishes proportion, rhythm and modularity before a single shape is drawn. The engineered aesthetic comes from precise alignment.

Grid rules

  • Snap-to-grid is always on. Every anchor point lands on an intersection.
  • Minimum shape size and spacing: 1 unit (equivalent to 8 px in the source system).
  • When shapes layer, keep at least 1-unit safe area between them.
  • Never eyeball placement. If an anchor doesn't sit on grid, delete it and try again.
02

Deconstructed.

Rectangles, circles, semi-rectangles and triangles are layered directly on the grid to build the subject. This stage is pure geometry — no fill, no color, just the primitives that will resolve into the silhouette.

Deconstruction rules

  • Only 4 primitives allowed — rectangle, circle, semi-rectangle, triangle.
  • Standard angles only: 0° · 15° · 30° · 45° · 60° · 75° · 90°.
  • Curves are quarter, half or full circles. Organic Bézier only when necessary, grounded in basic shapes.
  • Every visible primitive is a construction choice — remove what doesn't earn its place.
03

Outlined.

The primitives merge into a single wireframe silhouette. This is a blueprint stage — the moment where proportions get verified and the composition is committed. It is not a delivered style. If a user sees a red outline, they are looking at the blueprint, not the illustration.

Outlining rules

  • Single continuous outline per component. No hairlines, no dashed strokes.
  • Stroke width consistent across the illustration — a single voice.
  • Corner radius stays proportional and equal in nested shapes.
  • This stage is stored for review and version control, not for public delivery.
04

Final.

Colour, character and finishing details from the brand palette. This is the only stage that ships to product. It carries the same construction underneath — that's what makes different illustrations by different hands still feel like one voice.

Final rules

  • Colours only from the locked brand palette — Brand hero, Primary, Secondary, Base, Skin, Hair.
  • Opaque shapes preferred. Transparency / multiply used sparingly for depth.
  • Gradients allowed on select accents — refer to the 13 gradient paint styles on the DS home.
  • Every element is a Filled or Final variant — never an Outlined blueprint.
