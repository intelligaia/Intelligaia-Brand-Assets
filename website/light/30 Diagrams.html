Diagram library

Process graphics & flow charts

Purpose
Make one relationship legible at a glance — which workflow to automate, who decides what, what a change touches.
Format
1:1 canvas, 1400px PNG for screen, vector PDF for print and editing.
Patterns
Matrix, swimlane, hub-and-spoke, numbered journey, three-band process.
Convention
Title lock with the operative phrase underlined. One accent marks the path that matters. Tinted footer strip.
Reads
Matrix 2×2SwimlaneHub & spokeJourneyThree-band

One accentYellow marks the path that matters. Everything else stays neutral.
Three wordsNode labels of three words or fewer, or the diagram stops scanning.
Seven nodesMore than seven in one view and it needs splitting.
No legendLabel the nodes directly. A legend means the diagram failed.
Build it with AI

Hand this to an agent.

Prompt
Produce an Intelligaia process diagram for [TOPIC].

Playbook: 30 Diagrams.html

Pick one pattern:
  process-flow | matrix-2x2 | hub-spoke | journey-timeline

Inputs:
  title       statement; mark the operative phrase for accent
  axes        matrix only: x_label, y_label, low/high anchors
  nodes[]     name, qualifier, one example, icon slug
  highlight   which node or quadrant carries the accent
  footer      logo, one link

Output: SVG at 1080x1080 plus the JSON spec block.

Must

  • One accent — yellow marks the path that matters
  • Node labels of three words or fewer
  • Dashed connectors for flow, solid for structure
  • Seven nodes maximum in one view

Never

  • Crossing connector lines
  • Drop shadows or 3D perspective
  • Colour used decoratively
  • A legend — label the nodes instead
