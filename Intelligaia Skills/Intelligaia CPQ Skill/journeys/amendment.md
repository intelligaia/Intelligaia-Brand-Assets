# Amendment Journey

## Purpose
Change an active subscription/contract during term while preserving effective dating and downstream financial/operational integrity.

## L1
Identify active subscription → Select change → Configure delta → Price impact → Approve → Amend agreement/order → Billing/provisioning update.

## L2
1. Locate customer/account and active subscription/assets.
2. Select amendment effective date.
3. Choose change type: add-on, quantity expansion/reduction, upgrade/downgrade, term change, cancellation where applicable.
4. Load current configuration and entitlements.
5. Apply delta configuration rules.
6. Calculate pricing/proration/credit impact.
7. Validate co-term and term alignment.
8. Submit exception approvals if required.
9. Generate amendment documentation/agreement when needed.
10. Accept/eSign.
11. Create amendment order/change transaction.
12. Synchronize billing/provisioning.
13. Reconcile subscription/asset state.

## Critical controls
Effective dates, proration, entitlement eligibility, product compatibility, approval policy, contract terms, billing impact, downstream IDs, audit history.
