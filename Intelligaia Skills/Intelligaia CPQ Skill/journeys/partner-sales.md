# Partner Sales Journey

## Reference flow
Partner/customer context → eligible catalog/pricing → configure → quote → approvals/registration as applicable → order/status.

## Map each step
| Dimension | Capture |
|---|---|
| Persona | Actor and goal |
| Platform | System used |
| Input | Required data |
| Rule | Business/system rule |
| Output | Created/updated artifact |
| Handoff | Next system/person |
| Friction | Delay, re-entry, ambiguity, error |
| KPI | Time, touch, accuracy, conversion |

## Evidence rule
Do not assign a platform or automation behavior without validated evidence.
