# Source Provenance

For important claims record:
- Source / project
- Evidence type: interview, assessment, case study, user story, product documentation
- Evidence date or project period when known
- Platform/version context when known
- Finding
- Confidence: High / Medium / Low
- Status: Confirmed / Inferred / Unknown / Historical finding
- Current validation required: Yes / No

Historical product gap statements must never be silently converted into current platform facts.
