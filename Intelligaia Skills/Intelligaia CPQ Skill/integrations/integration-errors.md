# Integration Error Analysis

For each failure capture:
Source → Target → Trigger → Entity/ID → Validation failure → User-visible symptom → Business impact → Retry behavior → Reconciliation path → Owner → Monitoring.

## Common CPQ error classes
Missing/invalid master data; stale account/contact; product/price mismatch; quote/order discrepancy; failed opportunity/quote sync; billing-required field missing; duplicate transaction; partial update; subscription state mismatch.

These are diagnostic categories, not claims about a specific implementation.
