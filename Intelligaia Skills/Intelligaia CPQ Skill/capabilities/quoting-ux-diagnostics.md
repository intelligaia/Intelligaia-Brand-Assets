# Quoting — UX, Diagnostics & KPIs

## Seller Experience
A healthy experience makes completeness, current version, commercial values, approval state, proposal generation, blocking errors and revision differences clear while minimizing duplicate entry.

## Diagnostic Questions
- How long does a standard quote take?
- What is re-entered or managed in spreadsheets/documents?
- Can users identify the current authoritative version?
- When are errors discovered?
- Is proposal generation manually edited?
- Are revisions comparable?
- Does approval remain aligned to version?
- What blocks quote-to-order conversion?

## Customer Experience
Proposal should clearly communicate the purchased solution, quantities/configuration as appropriate, charges, dates/term, relevant terms, validity and acceptance mechanism.

## Common Failure Patterns
Treat as hypotheses until evidenced:
- ambiguous versions;
- proposal/quote mismatch;
- manual document editing;
- stale cloned pricing;
- approval attached to an old version;
- customer acceptance of a different version;
- expired quote progression;
- accepted quote unable to convert;
- quote/order line mismatch;
- downstream-required data discovered late.

## Diagnostic Framework
**Persona → Deal Type → Quote → Configuration → Price/Discount → Validation → Approval → Proposal → Revision → Acceptance → Order Handoff → Pain/Workaround → Evidence**

## Version Diagnostic
**Quote → Versions → Change Trigger → Approved Version → Proposal Version → Accepted Version → Ordered Version → Mismatch/Impact → Evidence**

## Quote-to-Order Diagnostic
**Accepted Quote/Line → Required Order Data → Transformation → Validation → Error → Manual Correction → Impact → Owner → Evidence**

## KPI Examples
Quote creation/cycle time; validation failures; revisions per quote; manual proposal edits; approval turnaround; accepted-to-order success; order errors caused by quote data; external spreadsheet/manual-document usage.

Do not invent targets.

## Opportunity Patterns
Completeness indicator, revision comparison, authoritative-version control, expiration warning, integrated proposal generation, acceptance tracking, quote-to-order readiness and reconciliation. These are Proposed until validated.
