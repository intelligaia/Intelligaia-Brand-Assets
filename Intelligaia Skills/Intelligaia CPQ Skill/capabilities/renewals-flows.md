# Renewals — Flows

## 1. Renewal Identification
1. Identify subscription/term approaching renewal according to policy.
2. Confirm renewal eligibility.
3. Retrieve authoritative current and pending subscription state.
4. Establish renewal date/window.
5. Identify customer/owner/channel.
6. Determine renewal motion: automatic, assisted, optional, or other evidenced process.
7. Create or schedule renewal transaction.

## 2. Renewal Readiness
Validate:
- subscription/source state;
- products and quantities;
- pending amendments;
- term/end date;
- pricing/contract references;
- product availability/migration needs;
- customer/account status;
- required renewal attributes;
- unresolved billing/entitlement exceptions where relevant.

## 3. Assisted Renewal
Create renewal opportunity/context → generate renewal quote from baseline → apply carry-forward/migration rules → price/uplift → allow permitted changes → discount → approve → negotiate → accept → order → create/continue renewed subscription term.

## 4. Auto-Renew
Identify eligible subscription → validate auto-renew conditions and notice/cancellation state → determine renewed term/products/quantities → apply approved commercial rules → create required lifecycle/billing transaction → notify where required → activate renewed term → reconcile.

Do not infer that auto-renew requires no quote/order.

## 5. Baseline Construction
Authoritative subscription + effective pending changes → determine products/quantities/configuration/term/commercial references eligible to renew → create renewal baseline → preserve source lineage.

## 6. Renewal Uplift / Repricing
Determine evidenced renewal pricing basis → apply contractual uplift/index/current pricing/other rule as applicable → calculate renewed values → expose change rationale → evaluate discount/approval.

## 7. Product Migration
Identify non-renewable/obsolete source product → find approved successor/migration path → map configuration/quantity → price target → identify customer/commercial impact → approve/accept → renew onto target product.

## 8. Renewal with Changes
Start from renewal baseline → add/remove/change eligible products or quantities → configure → price → discount/approve → calculate resulting renewed state.

Clarify whether these changes are treated within renewal or as separate amendment transactions.

## 9. Co-Term / Consolidated Renewal
Identify multiple eligible subscriptions/terms → determine target renewal date/structure → apply approved alignment/consolidation rules → construct combined renewal transaction → price/approve → execute → preserve source-to-result lineage.

## 10. Renewal Negotiation
Present renewal proposal → receive customer changes → revise → reconfigure/reprice/rediscount → reapprove where required → regenerate proposal → capture final decision.

## 11. Renewal Acceptance
Capture exact accepted renewal quote/version → validate approvals and dates → create renewal order/agreement according to process → establish next subscription term → preserve predecessor/successor relationship.

## 12. Non-Renewal / Churn
Capture non-renewal decision/reason according to policy → prevent unintended renewal → establish end-of-term behavior → update forecast/status → stop/adjust billing and entitlements at governed end date → preserve history.

## 13. Partial Renewal
Determine which products/quantities continue → identify non-renewed components → calculate renewed commercial state → execute continuation and end-state actions → reconcile.

## 14. Renewal Order
Accepted renewal → transform renewed products/charges/terms to executable order → preserve source subscription and renewal quote references → submit → update subscription/billing/entitlements.

## 15. Subscription Continuation
Prior term reaches boundary → establish renewed term/state → preserve predecessor/successor lineage → activate renewed products/charges → update renewal dates/status.

## 16. Renewal Failure / Exception
Detect missing/stale baseline, pricing failure, migration issue, approval delay, order failure or synchronization error → assign owner → remediate → prevent unintended lapse/renewal according to policy → reconcile.

## 17. Renewal Reconciliation
Compare:
renewal baseline + accepted changes → renewal quote → order → renewed subscription → billing → entitlement.
Flag unexplained differences.

## Flow Depth
L2/L3 vendor-neutral. Exact renewal automation, CRM opportunity behavior, quote generation timing, notice logic, billing mechanics and platform objects belong in platform/integration modules.
