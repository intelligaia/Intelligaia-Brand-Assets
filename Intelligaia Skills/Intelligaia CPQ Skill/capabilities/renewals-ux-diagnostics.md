# Renewals — UX, Diagnostics & KPIs

## Seller / Renewal Manager Experience
A healthy renewal experience should show:
- subscriptions approaching renewal;
- authoritative baseline;
- current products/quantities/term;
- pending amendments;
- renewal eligibility;
- products requiring migration;
- prior vs proposed commercial values;
- uplift/repricing explanation;
- customer changes;
- approval status;
- accepted/non-renewed outcome.

## Customer Success Experience
Useful visibility may include renewal date, adoption/entitlement context where permitted, pending issues, customer decision, contraction/expansion and next actions.

## Diagnostic Questions
- Are renewals identified early enough according to business policy?
- Is the baseline current?
- Are pending amendments included?
- Is renewal quote creation automated or manual?
- Can sellers explain uplift?
- Are obsolete products migrated consistently?
- Are prior discounts copied without review?
- Can partial renewals be represented?
- Are churn/non-renewal decisions propagated downstream?
- Does the renewed subscription match the accepted quote?

## Common Failure Patterns
Treat as hypotheses:
- spreadsheet renewal tracking;
- renewal opportunity missing/duplicated;
- stale installed base;
- pending amendment omitted;
- manual uplift calculation;
- expired/obsolete SKU renewed;
- wrong quantity carried forward;
- discount blindly copied;
- quote generated from prior quote instead of subscription;
- non-renewal not communicated to billing;
- entitlement continues after churn;
- gap/overlap between prior and renewed term.

## Renewal Diagnostic
**Source Subscription → Renewal Trigger → Baseline → Carry-Forward/Migration → Pricing/Uplift → Discount/Approval → Negotiation → Decision → Order → Renewed Subscription → Billing/Entitlement → Evidence**

## Baseline Diagnostic
**Current Subscription → Pending Changes → Expected Renewal State → Actual Renewal Quote → Difference → Cause → Impact → Evidence**

## Pricing Diagnostic
**Prior Price → Renewal Basis → Uplift/Repricing Rule → Discount → Proposed Price → Approved/Accepted Price → Explanation → Evidence**

## Churn Diagnostic
**Renewal Candidate → Customer Decision → Non-Renewal Scope → End Date → Billing Stop → Entitlement End → Forecast Update → Difference → Evidence**

## KPI Examples
Renewal identification/readiness rate; renewal quote lead time; renewal cycle time; manual touches; renewal quote corrections; uplift exceptions; migration exceptions; reapproval rate; on-time renewal completion; churn/non-renewal processing errors; renewal-to-subscription reconciliation exceptions.

Revenue-retention metrics such as GRR/NRR require explicit customer definitions before use.

## Opportunity Patterns
Renewal workbench, readiness scoring, baseline/current-vs-proposed comparison, pending-amendment awareness, uplift explanation, migration guidance, renewal timeline, churn workflow and automated reconciliation. Proposed until validated.
