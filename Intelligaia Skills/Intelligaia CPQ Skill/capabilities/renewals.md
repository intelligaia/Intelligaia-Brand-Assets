# Renewals

## Capability model
Renewal opportunity management → renewal quote automation → expiring/evergreen subscription logic → purchase history → renewal pricing/uplift → full/partial renewal → full/partial upgrade → add-on/quantity expansion → short/forward co-term → notification → approval → order/billing.

## Diagnostic questions
How are upcoming renewals detected? Are opportunity/quote records created automatically? Can sellers see prior purchases/pricing/discounts? How are add-ons and amendments reflected? Which scenarios remain manual? What third-party notifications are required? How are renewals synchronized to billing?

## Outcomes
Earlier action, less duplicate entry, lower Deal Desk/manual effort, accurate ARR context, improved renewal cycle time.
