# Amendments

## Scenarios
Quantity expansion/reduction, add-on, upgrade/downgrade, term/effective-date change, co-term, cancellation/termination where applicable.

## Analyze
Active subscription/asset context → effective change → delta configuration/pricing → approval → agreement/order update → billing/provisioning synchronization.

## Controls
Effective dating, proration/financial impact, eligibility, approval policy, downstream reconciliation, auditability.
