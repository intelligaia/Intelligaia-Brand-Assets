# Product Configuration

## Capability model
Product catalog → product model → attributes/options → bundles/offers → eligibility/visibility → constraints/dependencies → guided configuration/selling → validation.

## Product-model patterns
- Standalone product
- Solution bundle
- Marketing bundle
- Cross-product configuration
- Base + add-ons
- Subscription/service/hardware combinations

## Attributes vs options
Attributes capture configuration information that can influence features or pricing and can reduce SKU proliferation. Options are selectable sellable items in a bundle and may carry independent price/attributes/fulfillment.

## Assessment checklist
Product admin ownership; active product/family inventory; catalog hierarchy; product models; future models; visibility/constraint rules; EOL/EOS handling; change frequency; source of truth; downstream fulfillment/billing impacts; guided-selling needs; seller search/filter experience.

## Desired outcomes
Accurate configuration, reduced seller dependence, scalable catalog governance, and fewer downstream corrections.
