# Comparative Case-Study / Proposal Evidence — Wave 5

## Purpose
Use supplied case studies and proposals as bounded comparative evidence without converting another client's project, design or outcome into a target customer's fact.

- CommerceX Executive Presentation
- Cisco Commerce Case Study (already normalized in its dedicated evidence wave)

## Comparative Rule
A source can support:
1. a documented challenge in its own context;
2. a delivered/proposed solution in its own context;
3. a reported outcome in its own context;
4. a reusable **pattern to investigate** elsewhere.

It cannot, by itself, support:
- the same pain exists at another company;
- the same solution is appropriate;
- the same outcome is achievable;
- the same architecture/platform behavior applies.
