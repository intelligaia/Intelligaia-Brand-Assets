# Comparative Evidence Transferability

## Transferability Ladder

### Level 0 — Source-only
Keep the claim entirely within the source case/proposal.

### Level 1 — Investigation Pattern
The source suggests a useful question to ask another customer.

### Level 2 — Target Corroborated
Independent target-customer evidence confirms a similar problem/pattern.

### Level 3 — Target Recommendation Candidate
After target corroboration, a comparable approach may be considered subject to platform, process, policy, scale and operating-model fit.

### Level 4 — Target Validated
Target-specific design/configuration/testing/operational evidence validates the chosen approach.

## Mandatory Checks Before Transfer
- actor/persona equivalence;
- transaction/lifecycle equivalence;
- platform/version/configuration equivalence;
- commercial policy equivalence;
- integration/data ownership equivalence;
- scale/volume equivalence;
- regulatory/contractual context;
- implementation maturity;
- measurement definition and period.

## Quantified Outcomes
Never transfer a source metric as a target forecast without a separate target-specific value model.

Classify source numbers as:
**measured / reported / estimate / target / qualitative / unknown**.
