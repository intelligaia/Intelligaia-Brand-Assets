# CPQ UX Principles

1. **Unified task flow** — minimize context switching and duplicate entry.
2. **Recognition over recall** — expose relevant choices/rules/context at the moment of need.
3. **Status visibility** — approvals, quote state, order state, and errors should be understandable.
4. **Error prevention** — validate configuration and downstream-required data before submission.
5. **Progressive complexity** — standard deals should stay simple; advanced controls appear when needed.
6. **Seller guidance** — search, filtering, guided configuration, price explanation, and next-best action.
7. **Control and recovery** — allow safe revision, backtracking, correction, and clear error resolution.
8. **Consistency** — shared patterns/design system across CPQ surfaces.
9. **Persona relevance** — Seller, Deal Desk, Partner, Operations, Finance and Admin need different information density/actions.
10. **Prototype often** — test hero journeys and high-frequency scenarios throughout development.

## Audit
Review consistency/standards, recognition vs recall, user control/freedom, error prevention, task efficiency, accessibility, and cross-system continuity.
