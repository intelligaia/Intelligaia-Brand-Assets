# Gap Root Cause, Consequence & Dependency

## 1. Separate Gap from Cause
Gap:
required outcome is not met.

Cause:
why the outcome is not met.

A confirmed gap can have an unvalidated cause.

## 2. Root-Cause Domains
interaction → process → policy → catalog → pricing → data → integration → platform → security → performance → training → operating model.

## 3. Root-Cause Chain
**Gap → Immediate Cause → Contributing Cause → Authoritative Domain → Dependency → Evidence Needed**

## 4. Commercial Integrity
Check whether the gap can cause:
wrong product/configuration; wrong price; unauthorized discount; wrong quote/version; invalid approval; duplicate order.

## 5. Lifecycle Integrity
Check:
stale subscription baseline; missed pending change; wrong effective date; overlapping amendment; renewal on stale state; unintended cancellation.

## 6. Customer Impact
Potential:
incorrect proposal; delay; inconsistent commitment; order fallout; billing/service mismatch.

Only state observed impact as fact.

## 7. User Impact
Potential:
re-entry; rework; waiting; inability to complete; support dependency; comprehension burden.

Frequency/time require evidence.

## 8. Operational Impact
Potential:
manual correction; reconciliation; support cases; exception queues; data repair.

## 9. Financial Impact
Potential:
revenue leakage; margin risk; credit/rebill; delayed booking/renewal.

Treat as hypothesis unless quantified evidence exists.

## 10. Dependency Types
business decision → rule/policy → data → platform → integration → security → UX → operations → research.

## 11. Upstream
What must change before the gap can close?

## 12. Downstream
What else changes if the gap is closed?

## 13. Shared Cause
One root cause may produce multiple gaps. Link rather than duplicate fixes.

## 14. Local Fix Risk
A UI workaround may hide a data/integration problem and increase downstream risk.

## 15. Validation
For each hypothesized cause define:
evidence needed → owner/domain → discovery method → decision.

## Output
**Gap → Cause Status → Consequence → Risk → Dependencies → Related Gaps → Validation Needed**

## Guardrail
Do not present hypothesized impact or cause as validated fact.
