# CPQ Maturity Model

## Level 1 — Fragmented
Multiple tools, manual tracking, tribal rules, re-entry, weak status visibility.

## Level 2 — Standardized
Defined catalog/process, standard quoting and approvals, basic integration and governance.

## Level 3 — Integrated
Cross-system synchronization, controlled pricing/configuration, reliable quote-to-order, measurable SLAs/KPIs.

## Level 4 — Automated
Renewal/opportunity automation, pre-validation, intelligent routing, low-touch orders, self-service for standard deals.

## Level 5 — Optimized
Continuous UX/data optimization, advanced guidance, proactive exception management, high reuse, scalable channel/commerce patterns.

Score dimensions separately: Process, Platform, Data, Integration, UX, Governance, Adoption.
