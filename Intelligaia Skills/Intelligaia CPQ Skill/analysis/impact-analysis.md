# Impact Analysis

Evaluate impact on:
- Deal/quote cycle time
- Seller/partner productivity
- Win/conversion rate
- Deal Desk touch rate
- Approval turnaround
- Quote/order accuracy
- Support/rework volume
- Data quality
- Billing accuracy
- Adoption/self-service
- Scalability

Do not invent numeric benefits. Use baselines and targets only when supplied or explicitly modeled.
