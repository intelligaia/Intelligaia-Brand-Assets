# CPQ Roadmap Framework

## Sequencing principle
Fix foundational data/process dependencies before layering advanced automation.

## Reusable progression
### Get Ready
Data foundation, product/SKU/account rationalization, opportunity structure, core CPQ, standard pricing/discounts, standard approvals, document generation, quote-to-order, billing integration.

### Walk
Opportunity automation, enhanced configuration, attribute-based pricing where appropriate, CLM, renewal automation/integration, improved UX and collaboration.

### Run
Advanced pricing/approvals, bundling, partner/self-service commerce, marketplace motions, auto-booking, deeper automation and optimization.

## Workstreams
Data Foundation → Opportunity & Forecasting → Configure/Price/Quote → Contract → Order/Amend/Renew → Billing/Revenue.

Sequence is a framework, not a mandatory product plan.
