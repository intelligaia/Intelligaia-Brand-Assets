# CPQ Flow Analysis Framework

## Flow levels
- **L0** Revenue lifecycle: Lead/Opportunity → CPQ → Contract → Order → Billing/Revenue.
- **L1** Major business stages.
- **L2** Numbered user/system activities.
- **L3** Actor/action/rule/data/system detail with decisions and rework.
- **L4** Implementation detail such as object/field/API mapping only when validated.

## L3 template
| Step | Actor | Platform | Action | Input | Rule/Decision | Output | Error/Rework | Next |
|---|---|---|---|---|---|---|---|---|

## Mandatory overlays
Persona; system of record; data created/updated; approval/control; integration; UX; KPI; evidence status.

## Review questions
Where is work manual? Where is data re-entered? What causes waiting? Which decision lacks guidance? Which error appears too late? Where does the user lose status/context? What can be standardized versus exception-managed?
