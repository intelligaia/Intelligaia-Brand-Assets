Service Blueprint
Mapping the frontstage customer experience to the backstage systems and processes that must change to deliver it.

Blueprint focused on the Integration to First Transaction corridor. Frontstage actions: developer reads docs → creates API key → calls sandbox endpoint → verifies test payment → flips to live. Backstage: provisioning service latency (avg. 4.2 sec), manual KYB review queue (avg. 22 hrs), Slack-to-Zendesk handoff gap. Two critical front/backstage disconnects identified: (1) live-mode activation is automated but feels manual due to zero progress feedback; (2) KYB status is never surfaced to the developer UI.

Low Fidelity Wireframes
Rapid structural exploration of the redesigned onboarding, dashboard, and support flows — validated with 8 usability participants.

High Fidelity Mockups
Production-ready designs for web and mobile — 22 screens across onboarding, dashboard, and support — handed off via Figma Inspect.

Platforms: Web (1440px) and iOS / Android (390px).
