Design Foundation · Illustration

A visual system for AI-native storytelling.

The rules, ratios, and reference points that make an Intelligaia illustration look like Intelligaia — across decks, docs, web and product. Intent-aware by construction, designed to scale across human and agent surfaces.

01 / Pillar

Intent first.

Every illustration begins with a question — what should the viewer understand in two seconds? Tools are answers. The question comes first, the picture follows.

02 / Pillar

System over taste.

Repeatable rules outlast arbitrary choices. The framework gives every contributor the same shelves, hinges and joints — personal style still lives, it just lives inside the grammar.

03 / Pillar

Read at glance.

Agentic interfaces are read at scan-speed. If the picture takes ten seconds to parse, it has failed. Simplicity is not minimalism — it is respect for the viewer's time.

Part 03 / 04

Form fundamentals.

Before light, before character, before scene — the bones. How color reduces, how surface fills, how shape behaves, how depth is chosen, how the world is seen.

3.1
Palette System
How color is reduced to something intentional and prompt-ready.
AAnchored draft

One hue. Four shades. Calm, focused, scales easily across an entire set of agent surfaces.

  • shades4 (incl. ink + surface)

BLayered draft

Base hue + one accent + a neutral. The everyday working palette — disciplined, with room to point.

concept concept-B.svg
example palette-layered.svg 1200 × 900
  • use whenmost editorial & spot illustrations
  • shadesbase ladder + accent + neutral
  • accent rule≤ 10% area
  • tagsdefaultaccent-led
CSpectrum draft

Three balanced hues + neutral. The story-mode palette — used when an illustration must carry a narrative on its own.

concept concept-C.svg
example palette-spectrum.svg 1200 × 900
  • use whenhero, cover, narrative scenes
  • shades3 hues + neutral
  • balance60 / 30 / 10 area rule
  • tagseditorialnarrative
✱

Contrast between the lightest and darkest shade should never collapse below 4.5 : 1.

Background tone is part of the palette — choose it before you start, not after.

Neutrals carry the composition. Hues are the spice — never the meal.

3.2
Fill Method
How a shape is filled — pick one dominant, mix the others sparingly.
AOutlinedraft

Pure line geometry. Reads as schematic, technical, system-aware — the default for diagrams and product flows.

conceptconcept-A.svg
examplefill-outline.svg1200 × 900
  • stroke1.4 – 1.8 px
  • corners2 px radius
  • use whendiagrams, agent flows
BFlat Filldraft

Uniform color regions, no gradients. The everyday workhorse — fastest to produce, easiest to keep consistent.

conceptconcept-B.svg
examplefill-flat.svg1200 × 900
  • strokeoptional 1 px hairline
  • overlapmultiply mode for shadow
  • use whenmost spot & inline work
CVolumetricdraft

Gradient-driven depth. Used sparingly — for hero scenes, AI-substance illustrations, anything that needs to feel alive.

conceptconcept-C.svg
examplefill-volumetric.svg1200 × 900
  • gradient2-stop, linear or radial
  • budget≤ 3 fills per scene
  • use whenhero, cover, AI-substance
✱

Mixtures are common — outline + flat + a single gradient is the workhorse.

Stroke weight defines the system's voice. Pick once, lock it.

Multiply over color is cheap, consistent depth — use it before reaching for gradients.

Form Logic
The skeleton of the style — straight rules, curved rules, or a deliberate negotiation.

Continuous curves, soft transitions, hand-drawn logic. Used for human stories, empathy maps, anything warm.

  • cornersno sharp angles

CMixeddraft

Constructed frame with organic accents (or the reverse). The default for human-AI scenes — discipline plus humanity.

conceptconcept-C.svg

Coherence across elements matters more than any single decision.

Set rules of behavior up-front — "corners are always 4-radius" is a real rule.

Applied foundations.

Punctuating glyphs — dots, arrows, ticks, tiny letters. The smallest atoms of the system, used to add meaning and rhythm.

Build a small accent library before you commit — try, save, retry.

05 / Insight

Three thoughts to leave with.

A system is not a cage — it is the soil. Pick the rules so the work compounds, not so the work is solved.

01 / Insight

Everything is a system.

Even a single illustration is a system of choices. Name the choices, repeat the choices, the system writes itself.

02 / Insight

Rules before pixels.

Spend the first hour deciding the grammar. The next hour will be three times faster — and the tenth ten times faster.

03 / Insight

Learn by looking.

The fastest way to get better is to study what is already good. Steal the principle, not the picture.
