Landing page hero.

Produce a landing-page hero block in the Intelligaia visual language. Follows the yellow-banner treatment used on this site and on intelligaia.com.

Purpose

A hero block that lands the offer in under five seconds and gives the reader exactly one place to click.

Inputs
HeadlineMax 8 words. Oswald Bold. State the outcome, not the feature.Required Sub-copyMax 24 words. Geist Regular. One sentence describing the offer.Required CTA labelMax 3 words. Action verb + noun ("See portfolio", "Book workshop").Required CTA hrefDestination URL for the button.Required IllustrationPath from Assets/ — a Character, Device, Nature or Object final PNG.Required
Recipe

  1. Set the hero container

    Full-bleed background: #FFC800. Inner content in a max-width: 1440px container with padding: 80px 48px.

  2. Grid the content

    Two columns: text on the left (1.4fr), illustration slot on the right (1fr). Gap 48px. Vertical alignment centre.

  3. Type the headline

    Oswald 700, clamp(48px, 6vw, 88px), line-height: 0.98, letter-spacing: 0.01em. Max 20ch width.

  4. Type the sub-copy

    Geist 400, 20px, line-height: 1.5, opacity 0.85. Max 60ch width. One sentence — never two.

  5. Place the CTA

    Inline flex pill: background: #121212, color: #FFC800, padding: 14px 32px, border-radius: 999px. Geist Medium 16px. One CTA only.

  6. Drop the illustration

    Inside the right column at object-fit: contain, max-height: 480px. Pull only from Assets/ — never inline SVG.

Guardrails

DO

  • Use yellow (#FFC800) for the full hero background
  • Use exactly one CTA button
  • Pull the illustration from Assets/ folders
  • Keep the headline to 8 words maximum
  • Use Oswald Bold for the headline, Geist for the sub-copy

DON'T

  • Add a second CTA or navigation link in the hero
  • Recolour the yellow field to any other palette colour
  • Use gradient paint styles or secondary/skin palette in the hero
  • Add italic, shadow, gradient or animation to the headline
  • Inline-write an SVG illustration in place of an asset
