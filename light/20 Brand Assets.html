Brand assets

Every asset, one system.

Illustrations, icons, waves and letterforms — all built from the same three primitives on the same grid.

The system

Every asset from the same three primitives.

Circle, rectangle, line — placed on a 50×50 grid, built through four stages, filled from four brand colours. That constraint is what makes an Intelligaia illustration recognisable at a glance.

Grid

50 × 50

Every shape snaps to the dot-pixel grid before detail is added.

Primitives

Three shapes

Circle, rectangle, line. Nothing else is drawn freehand.

Stages

Four steps

Deconstructed → outlined → filled → final.

Palette

Four colours

Yellow, ink, blue, purple. Flat fills only.

Method

How a new asset gets made.

Follow this when the library doesn't already have what you need. Never generate an illustration outside the process.

Place on the grid

Start on the 50×50 dot grid. Block the silhouette with circles and rectangles only.

Deconstructed
Trace the contour

Resolve the primitive stack into a single stroke outline. No fills yet.

Outlined
Apply flat colour

Fill from the four brand colours. No gradients, no tints outside the palette.

Filled
Add depth

Shading, highlights, small detail. This is the production-ready stage.

Final
Name and file

Follow the naming convention, export PNG + SVG, add to the manifest.
